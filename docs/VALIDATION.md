## 复现

```bash
DOTNET_BIN=/path/to/dotnet bash scripts/verify.sh
DOTNET_BIN=/path/to/dotnet bash scripts/publish-windows.sh
```

本机协议测试需两个终端，不访问真实云服务：

```bash
# 终端 1
deno run --allow-net=127.0.0.1:54329 scripts/realtime-fixture.ts
# 终端 2
dotnet run --project apps/classroom/Broadcast.Core.Tests -- --realtime
```

校验发布文件：进入 `artifacts` 后执行 `shasum -a 256 -c SHA256SUMS.txt`。
